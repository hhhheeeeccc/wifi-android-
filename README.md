## المميزات (Features)

- **واجهة مستخدم احترافية (RTL)**: تصميم عصري يدعم اللغة العربية بالكامل.
- **تفعيل ذكي للبث**:
  - **أندرويد (Root)**: تفعيل صامت ومباشر باستخدام أوامر `cmd tethering`.
  - **أندرويد (Reflection)**: محاولة التفعيل المباشر للأجهزة بدون روت.
  - **أندرويد (LocalOnly)**: تفعيل البث للمشاركة المحلية كخيار بديل.
- **دعم رموز QR**: توليد رموز QR لتسهيل انضمام الأجهزة الأخرى للشبكة بسرعة.
- **إدارة المتصلين**: مراقبة الأجهزة المتصلة، حظر الأجهزة، وتحديد السرعة.
- **استقرار عالٍ**: تم إصلاح مشاكل الانهيار السابقة وتحسين استهلاك الموارد.

## هيكلية المشروع (Architecture)

تم بناء المشروع باستخدام لغة Java واتباع أفضل ممارسات تطوير تطبيقات أندرويد:
- `MainActivity.java`: إدارة الواجهة الرئيسية والمنطق الأساسي.
- `HotspotManager.java`: المحرك المسؤول عن التحكم في نقطة الاتصال.
- `ProxyManager.java`: إدارة اتصالات البروكسي وتوجيه البيانات.
- `UsageMonitorService.java`: خدمة خلفية لمراقبة استهلاك البيانات.

## طريقة البناء (Build Instructions)

إذا كنت ترغب في بناء التطبيق بنفسك:
1. تأكد من تثبيت **JDK 17**.
2. قم بإعداد **Android SDK** (API 33 أو أعلى).
3. استخدم Gradle لبناء المشروع:
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
